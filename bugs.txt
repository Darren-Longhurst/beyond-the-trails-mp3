Testing Technical Challenge
Issue: The test runner failed to build the test database due to a psycopg2 relation error (auth_user does not exist). Analysis: This was identified as a race condition where model defaults were referencing the User table before the test database had completed its initial migration. Resolution: I configured the test environment to use an in-memory SQLite database specifically for unit testing.
